# Ручные формы склонения ФИО (T035)

Пример на случай, когда автоматическое склонение фамилии не устраивает.

## В чём дело

Фамилии-нарицательные (Бивень, Кузнец, Мороз) движок по умолчанию
**оставляет в именительном падеже** — в официальном документе безопаснее
не склонять вовсе, чем склонить неверно (правило T027). Но иногда форма
известна и нужна именно она.

Тогда её задают вручную в `dyak.yaml`, секция `overrides.fio`. Ключ —
ФИО целиком, как в таблице.

## Файлы

| Файл | Назначение |
|---|---|
| `employees.xlsx` | Две строки: «Бивень Абрам Моисеевич» (проблемная фамилия) и «Иванов Пётр Семёнович» (обычная, для контраста). |
| `order_template.docx` | Шаблон с `{{ ФИО \| дт }}`, `{{ ФИО \| рд }}` и `{{ Инициалы }}`. |
| `dyak.yaml` | Ручные формы для «Бивень Абрам Моисеевич» — пять падежей. |
| `out_default/` | Результат **без** настроек. |
| `out_manual/` | Результат **с** настройками. |

## Запуск

Из корня репозитория — **без** настроек:

```bash
PYTHONPATH=src uv run python -m dyak generate \
  --table examples/manual_forms/employees.xlsx \
  --template examples/manual_forms/order_template.docx \
  --out examples/manual_forms/out_default
```

и **с** настройками:

```bash
PYTHONPATH=src uv run python -m dyak generate \
  --table examples/manual_forms/employees.xlsx \
  --template examples/manual_forms/order_template.docx \
  --config examples/manual_forms/dyak.yaml \
  --out examples/manual_forms/out_manual
```

## Разница

Без настроек фамилия остаётся как есть:

```
Объявить благодарность Бивень Абраму Моисеевичу, начальнику склада, …
Основание: представление Бивень Абрама Моисеевича.
```

С настройками подставляется заданная форма:

```
Объявить благодарность Бивню Абраму Моисеевичу, начальнику склада, …
Основание: представление Бивня Абрама Моисеевича.
```

Обратите внимание: «Иванов Пётр Семёнович» в обоих случаях склоняется
одинаково — ручные формы задаются точечно и на остальных не влияют.

## Что важно знать

- **Ключ — ФИО целиком.** Заданная форма подставляется целиком туда, где
  в шаблоне стоит `{{ ФИО }}` с падежом. Отдельные части
  (`{{ Фамилия | дт }}`) и инициалы движок по-прежнему склоняет сам:
  разобрать готовую форму обратно на фамилию, имя и отчество нельзя —
  как раз в тех случаях, ради которых ручная форма и задаётся.
- **Падежи можно указывать не все** — остальные возьмёт движок.
- **Сухой прогон `check` видит ручные формы** и не ругается на то, что вы
  уже поправили.
- **В графической оболочке** файл настроек указывается в поле
  «Настройки (необязательно)» на вкладке «Генерация».

> **Осторожно с рабочей папкой.** Если `--config` не указан, ядро ищет
> `dyak.yaml` в **текущей** папке. Поэтому запуск из
> `examples/manual_forms/` подхватит здешний конфиг сам — и разницы вы не
> увидите. Команды выше запускаются из корня репозитория именно поэтому.
